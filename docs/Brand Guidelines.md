# Brand Guidelines

## Working name

**Creator Command Center**

This is a descriptive working name. It may remain the product name or later become a product subtitle beneath a distinct brand mark.

## Brand position

A private, premium creator workspace that helps streamers move from scattered tools to confident, informed action.

## Personality

- Calm, capable, and focused.
- Futuristic without being flashy.
- Helpful without talking down to the creator.
- Precise, trustworthy, and human.

## Voice

Use short, clear language that tells the user what happened and what can happen next.

| Prefer | Avoid |
| --- | --- |
| “OBS is connected. Ready when you are.” | “System operational.” |
| “Your post-stream review is ready.” | “Analytics ingestion completed.” |
| “Review before publishing.” | “Autonomous content distribution.” |
| “2 tasks need your attention.” | “Actionable items detected.” |

## Visual direction

The visual system is **Cyberpunk Executive**: graphite surfaces, smoky depth, small neon cyan signals, restrained violet accents, and generous typography. See `Design System.md` for tokens and components.

## Logo guidance

Future logo exploration should favor a minimalist geometric mark that works at 16px and as a desktop dock icon. Potential motifs:

- A modular command-grid or control-node symbol.
- A subtle `C`/`C` monogram formed by connected segments.
- A beacon, waypoint, or coordinated orbit—abstract rather than literal.

Avoid microphones, game controllers, Twitch-like shapes, mascots, and overly detailed cyberpunk illustrations.

## Iconography

- Use a consistent rounded-line icon set.
- Icons should communicate purpose before style.
- Use cyan only to communicate active/primary status; use violet for AI-specific features.
- Pair unfamiliar icons with labels or accessible tooltips.

## Photography and illustration

Keep background visual assets minimal. If used, favor abstract dark architectural light, subtle grid textures, or soft-glow technical forms. Avoid busy gamer-room imagery, neon overload, or copyrighted platform branding as decoration.

## Naming patterns

- Screens: Mission Control, Streaming, Analytics, Content, Automations, AI Workspace, Settings.
- Statuses: Ready, Live, Needs review, Paused, Connected, Offline, Failed.
- Actions: Start stream, End stream, Review session, Create draft, Run preview, Approve action.
